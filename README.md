# Anitop Events website draft

A static, responsive draft for Anitop Events and its two divisions: Event Planning and Local & International Furniture.

## Preview

Open `index.html` directly, or run a local server from this folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — semantic page content and metadata
- `styles.css` — mobile-first responsive styling
- `script.js` — navigation, reveal effects, and WhatsApp/email form handoff
- `assets/anitop-flyer.jpg` — supplied visual brand reference
- `assets/furniture-living.jpg` and `assets/furniture-dining.jpg` — locally saved illustrative sample imagery from Unsplash (not claimed inventory)
- `assets/favicon.svg` — local brand-mark favicon

## Before publishing

Replace the clearly marked event placeholder and illustrative furniture samples with approved, optimised business images/catalogue photography. Confirm furniture product/category wording and provide a production domain for canonical URL metadata. No backend is used; form submissions open WhatsApp or the visitor's email app.
